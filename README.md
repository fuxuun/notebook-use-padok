## 让读、写、想，留在同一本笔记里

阅读一份讲义，直接圈出重点；遇到一道需要推演的题，打开无限草稿本接着写。轻记把导入资料、手写批注、草稿记录和本地备份放在一起，适合带笔的 Android 平板。

无需注册账号。应用不申请联网权限，笔记保存在设备中。

| 你想做的事 | 轻记提供的工具 |
| --- | --- |
| 在资料上划重点 | 压感钢笔、半透明荧光笔、整笔橡皮、颜色与粗细调节 |
| 整理刚写下的内容 | 套索圈选，移动、缩放、复制、删除笔迹，支持撤销与重做 |
| 画示意图或做题 | 直线、矩形、圆形／椭圆，以及可编辑、移动的文字框 |
| 阅读一整本长 PDF | 连续上下滚动、单页模式、缩略图与输入页码跳转 |
| 随手演算、展开想法 | 四向延伸的无限草稿本，双指缩放，查看全部内容 |
| 把笔记带走 | 自动保存、带批注 PDF 导出、可恢复编辑的 ZIP 备份 |

白纸、横线、方格三种纸张可选；分页笔记可以追加和删除页面。默认触控笔书写、手指导航，没有触控笔也可开启「手指书写」。

> 顶部封面是产品视觉插画，并非应用截图。压感与手掌防误触表现取决于设备支持。

## 下载安装

**当前版本：1.1.0 体验版 · Android 10+ · APK 约 7.50 MB。**

在本仓库的 **Releases** 中下载 `轻记-1.1.0.apk`，传到设备并点击安装。源码 ZIP 用于开发，不是安卓安装包。如果尚未看到 Release，说明安装包还未发布。

已有本项目 1.0.0 安装包的用户可覆盖更新到本次提供的 1.1.0；建议先备份笔记，**不要先卸载**。自行构建的 APK 签名可能不同，不能保证覆盖安装。

开始使用：新建笔记或导入资料 → 选择工具书写 → 等待“已保存到设备”。长文档点击底部页码可直接跳转；新建时选择「无限草稿本」即可自由展开。

## 支持哪些文件？

| 格式 | 导入方式 |
| --- | --- |
| PDF | 保留页面尺寸，支持多页批注 |
| JPG / PNG | 按比例放入 A4 页面 |
| TXT / Markdown | UTF-8 纯文本，自动换行分页；不解析 Markdown 排版 |
| DOCX / PPTX / XLSX | 在本机转换为可批注页面，尽量保留常见文字、图片、表格和位置 |

**Office 导入是轻量转换。** 复杂排版、特殊字体、公式和图表可能有差异。Excel 使用已有公式缓存，不重算公式，暂不转换浮动图片及图表。旧版 DOC / PPT / XLS 请先另存为新格式；需要精确版式时，先用 Office/WPS 导出 PDF。

## 保存与导出

- 完成笔画、擦除或文字修改后自动保存。保存失败时保留未保存内容并提示重试。
- 导出 PDF 将背景、笔迹和文字合成为图片，适合阅读与打印，不能复制原 PDF 文字。
- ZIP 备份保留可编辑笔迹和文字框，恢复时创建新笔记，不覆盖现有内容。
- Office 备份保存转换页面及批注，请另行保管原 Office 文件。
- 无限草稿导出 PDF 时收纳为单页，范围越大，内容显示越小。

本地笔记会随卸载应用而删除，请把备份保存在应用以外的位置。

## 技术与构建

原生单模块应用：**Kotlin · Jetpack Compose · Room · Jetpack Ink 1.0.0**。文件选择、PDF 渲染与导出采用 Android 系统能力，不依赖服务器。

JDK 17、Android SDK 36、Build Tools 35.0.0 准备好后：

```powershell
.\gradlew.bat assembleRelease
```

产物位于 `app/build/outputs/apk/release/app-release.apk`。当前构建使用开发签名；维护长期更新时请妥善保管签名密钥。
